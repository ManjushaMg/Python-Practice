THE PROGRAMMES

1.Number guessing game: For that I have used random() function to create the secret number, prompted the user for guessing the number, and set condition that the the guessed number should be between 1 and 10 and limited the user to 3 attempts .
Then I used conditional statements(if,elif,else) to check whether  the number above , below or equal to the secret number .For each condition i have added comments for eg: if the number below the secret number it prints
"Sorry, it's just lower than secret number".
I used while loop to check the condition and the break, continue to exit the loop when the condition is met and to skip the iteration if the guess is out of range

2.Multiplication calculator:I  created a multiplication calculator using for loop.Prompted the user to enter the value of which the multiplication table should be generated.Then i used loop to calculate and display output in the multiplication table format

3.BMI calculator:Created a BMI checking calculator using a function.Applied its formula to calculate the user's BMI, printed it and finally called the function to display it
