Data Visualisation using Matplotlib and Seaborn:

This assignment focuses on exploring and visualizing a Taxi Trip Dataset using Python libraries such as Matplotlib and Seaborn


Steps followed:

1.Imported data to the Jupyter notebook.The dataset contains information about taxi trips, including pickup and dropoff locations, number of passengers, distance, fare, tips, tolls, payment methods, and boroughs.

2.I cleaned the dataset(Checked for missing values , handled missing values to prepare the dataset for visualization)

3.Visualisation using Matplotlib:

Line Chart to visualize the fare over time

Bar Chart   to show the total fare for each pickup_borough

Pie Chart  showing the distribution of trips based on the payment method (credit card, cash, etc.)

Histogram  to visualize the distribution of distance

Box Plot   to visualize the distribution of tip amounts for each pickup_borough. 


4.Visualisation using Seaborn:

Count Plot  to visualize the number of trips in each pickup_borough

Scatter Plot  to show the relationship between distance and fare

Heatmap  to visualize the correlation between numerical variables such as distance, fare, tip, tolls, and total

Pair Plot to visualize the pairwise relationships between distance, fare, tip, and total

Violin Plot   to show the distribution of fare for each payment method
